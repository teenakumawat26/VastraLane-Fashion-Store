# VastraLane - Fashion Store 👗

A modern, fully responsive fashion e-commerce website for Men, Women, Kids & Beauty collections.
LIVE DEMO : https://teenakumawat26.github.io/VastraLane-Fashion-Store/

**Tech Stack:** HTML, CSS, JavaScript

### ✨ Features
- Category Filter (All, Men, Women, Kids, Beauty)
- Trending Styles Section
- Wishlist & Shopping Bag
- Low Stock Alert - Only 2 left!
- Product Ratings & Search,order 
- WhatsApp Order Integration
- Fully Responsive Design
